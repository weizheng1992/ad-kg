# T3 统计型真实化题（8~10 题）

## Question

统计类问句现有覆盖挂在 fact 型下（G06 排序/G07·G36 平台汇总/G08 等单实体均值），措辞书面且量少。本票出 **8~10 题真实措辞统计题**打 `/agent/chat`：

- **问法覆盖**：聚合汇总（"各平台花了多少"口语变体）、TopN 排序（含方向反转——成本型越低越好）、时间窗（"上个月""最近三个月"口语指代）、分母口径（matched 行 HAVING 门槛的自然语言变体）
- **数值锚点铁律**：每题 must_numbers 从库值锚定（T1 机制）；**汇总比口径断言**——比率型跨行聚合必须 sum(分子)/sum(分母)，禁 avg 行比率（G32–G34 曾因旧口径漂移 2~3 倍，本题锚定即防复发）
- **定调 HITL**：同 T2，先 2~3 样例拍板
- **角色覆盖**：管理层为主；财务角色测指标级权限（毛利/ROI 类 finance_owner 面）；至少 1 题"无数据窗口"诚实回退（空窗回退注明）
- **判据**：judge 要点 + must_numbers 全中（锚点全中是硬门，不允许静默错答）；≥90% 连续两轮

## 验收

- 题库文件入 `eval/`，数值锚点全部落盘且有 recalc 对账（种子将来扩容时可重算）
- 全题实弹两轮达标；sql_source 来源标注在报告可见（不进判据，只观察——雾区项）
- 报告落 `eval/runs/`；文档同批改

## Answer（2026-10-30 实弹收官）

**交付**：query 型旁的 stat 型 10 题（A13–A22，加 A01 共 11 统计场景）+ recalc_agent 锚点五种新增/扩展（window_top_metric 含方向/平台过滤、sum_metric 含窗口、platform_cost 加窗、platform_metric 平台均值）+ 执行器 num_ok 两处保真（千分位逗号、百分号语义）。

**定调**（用户拍板）：排序族 A01 垫底；汇总（A13 platform_cost）/指标级权限（A14 creative CPA 派生联动拒答）/空窗回退（A15 本月 0 行）三样定调；覆盖排序×4（desc/asc/平台过滤/ctr）、均值锚×2、和值×3、空窗×1、权限×1。

**实弹**：3 次全量跑收敛，收官 10/11 → 11/11 两轮达标（报告 agent-20261030-212254）。pytest 全量 308 绿。

**最大战果——真缺陷一枚（静默错答风险面）**：A21 原题"上月总共烧了多少"系统答 **46,040**，库值真 **93,954**——**品牌 top5 榜（LIMIT 5）被当作总量呈现**（5 家之和=46,040 对榫）。agent 有标注"证据仅覆盖 5 个品牌"但标题数是部分和，judge 因证据有数放行——**数值锚硬门唯一能逮住它的关卡**。出界记档（引擎缺口③，优先级最高：真实用户可直接被误导）。

**其余发现**：
- **检索缺口 +2（出界）**：素材中文名→素材级指标绑定缺失（A17/A22 原稿中文名查不到，ask 面只认 ID/slug，agent 诚实报"只有平台级汇总"）；排序题证据溯源不可见（A16 原题证据不带平台/时间标注，judge 无法验证 scope，agent 自提醒"建议二次核对"）。
- **种子陈旧性活体**：任意"最近 N 天/本月"从今天滚动必落空档（数据止于 9-28）——A21 原稿"最近一个月"先被引擎解析为本月日历窗（空窗撞 A15），改"过去三十天"仍是 10-01~10-30 空档，最终改"上个月"落锚。golden data_window 注记的实证。
- **路由事实**：聚合/排序/窗口/平台过滤/均值五族经 agent 面全部稳定可达（收官轮 11/11）；"投放费=cost""获客成本=CPA""难看/烧钱"等口语映射 judge 全接住。
- **评测者伪影 +2（已修+钉测试）**：千分位逗号劈数字（1,001,609.41→三 token）；百分号语义（"1.64%"读成 1.64，按 % 后缀 /100 候选修正）。

**给后续票的事实**：
- stat 题面最稳粒度：平台维度拆分/平台均值/ID 形态均值锚/窗口 top（五族收官轮全绿）。
- "总量"类问法在引擎补总量路径前**不要进题库**（现答部分和）。
