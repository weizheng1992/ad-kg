# T4 对比型真实化题（6~8 题）

## Question

对比型问法 golden set 目前 **0 题**。本票出 **6~8 题真实措辞对比题**打 `/agent/chat`，三形态全覆盖（制图拍板 d）：

- **双实体对比**（2~3 题）："素材 A 和素材 B 哪个 CPA 好？"——断言两边数值都出且结论方向正确
- **双平台/双品牌对比**（2~3 题）："抖音和小红书哪边 CTR 高？"——跨行聚合仍守汇总比铁律
- **双期间对比**（2 题）：本月 vs 上月消耗/CPA——**text2sql 时间窗交叉是硬骨头**（两个窗口独立聚合再比），预期最难点，单独调试；跑不动时允许降级为"诚实说明不支持+给出两个单窗口结果"（判据按降级诚实口径写，不算静默错答）
- **角色与越权**：对比的两实体分属不同可见范围时，期望只比可见的那边并诚实说明（fail-closed 面的真实化测试）
- **判据**：judge 要点 + 双边 must_numbers 锚点 + **结论方向断言**（谁高谁低不许说反）；≥90% 连续两轮

## 验收

- 三形态题齐且锚点落盘；期间对比题处置结果（跑通或诚实降级）在报告明确记录
- 全题实弹两轮达标；报告落 `eval/runs/`；文档同批改
