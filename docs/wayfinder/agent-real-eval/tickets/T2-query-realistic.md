# T2 查询型真实化题（8~10 题）

## Question

现有 38 题的查询类（fact/multi_hop）措辞全是干净书面语（"李昂负责哪些 Case？"）。本票出 **8~10 题真实措辞查询题**打 `/agent/chat`：

- **真实措辞构成**（制图拍板）：口语化（"小李手上有什么案子"）、业务行话、模糊指代（"那个效果不好的素材"）、**一问夹两事**（"王雪对接的是哪个品牌？她最近负责的案子效果咋样"）
- **定调 HITL**：先出 2~3 题样例给用户拍板（口语浓度/模糊度/行话密度），定调后批量补齐，不再逐题过目
- **角色覆盖**：管理层/优化师/客户至少各 2 题；至少 1 题越权问法（客户问别的品牌，期望被行级过滤滤掉且答案诚实说明）
- **判据**：judge 要点 + must_entities 实体锚（数值锚点视题而定）；走 T1 执行器，每型 ≥90% 连续两轮
- golden 38 题零改动

## 验收

- 题库文件入 `eval/`（T1 定的形状），样例定调记录留痕（题文件 notes 或报告）
- 全题实弹两轮达标；越权题断言"滤掉+诚实"双条件
- 报告落 `eval/runs/`；README/CLAUDE.md 若动到命令/口径同批改
