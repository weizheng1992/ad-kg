## 2. 认证（M1）

**账号**：新表 `app_user(id, username UNIQUE, password_hash, display_name, role, person, disabled, created_at)`。
哈希用 **stdlib `hashlib.scrypt`**（N=2^14, r=8, p=1，per-user salt，格式 `scrypt$<salt-b64>$<hash-b64>`）——零新依赖、内存难解；面试话术与 bcrypt 等价成立。开户/重置走 `scripts/init_users.py`（初始账号与 Person/演示期一致：li/wang/zhao/zhou/chen/sun/gu(client_a)/admin；密码来自 `.env ADKG_USER_PASSWORD`，无则随机生成并打印一次）。

**会话**：表 `app_session(token PK, user_id, created_at, expires_at)`，token=`secrets.token_urlsafe(32)`，有效期 7 天滑动（每次 `/auth/*` 校验时顺延）；cookie 名 `adkg_session`，`HttpOnly; SameSite=Lax; Path=/`（部署态 nginx HTTPS 下加 `Secure`）。可吊销（删行即失效）。

**端点**：`POST /auth/login {username,password}`（成功 set-cookie 并返回 `{username, display_name, role, person}`；失败 401 且审计 deny）、`POST /auth/logout`、`GET /auth/me`。登录成败均写 audit_log（action=login）。

**解析顺序**（`guards/http.py::resolve_identity` 扩展，其余端点零改动）：
1. `Authorization: Bearer` service token（smartServe / eval 脚本路径，**不变**）
2. `adkg_session` cookie → app_session 未过期 → `(user.role, user.person)`
3. dev 路（`ADKG_DEV_AUTH=off`，本地/测试，**不变**）

**web 侧**：`session.tsx` 改为 `/auth/me` 驱动；`LoginPage` 真登录；`accounts.ts` 删除；所有 api 调用不再传 role/user（同源 cookie）。vite 代理与 nginx 均加 `/auth`；nginx 配置**删掉 token map**（`deploy/nginx/adkg-demo.conf`），API 反代加 `/auth|/creators|/brands|/settlements|/stats|/admin`。

## 3. 本体扩展（M2）

**schema.yaml**：
- `Creator`（达人/创作者主数据）：`properties: [name, platform, niches, followers, quote_20s, quote_image, gmv_30d, city, rating]`（niches=主要视频方向，list）
- `Case.properties` 增 `lost_reason`（proposal→lost 拒因；terminated 已有 terminate_reason）
- 关系：`Case→collabs_with→Creator (N:M)`、`Creator→promotes→Product (N:M 带货)`

**permissions.yaml**：`ae/optimizer/finance/management` 的 classes 增 `Creator`（client、creative 不加——外部与创意角色不见达人库）；Creator 为内部主数据类，不设 row_filter（合作历史经 Case 的行过滤收敛）；finance 对 Creator 全字段可见（报价/结算列）。达人指标（gmv_30d）属属性非指标列，不进 metrics 权限宇宙。

**种子**（gen_seed 幂等，`random.seed(42)`）：达人 20 个（id `Creator:cr01…`，§12.5 格式），niches 与既有 8 品牌品类对齐（露营/美妆/宠物/健身…），粉丝 5w–800w、20s 报价 2k–15w、30d GMV；`collabs_with`：live/closed 案例 1–2 达人/单；`promotes`：按品类匹配 SKU；3 个 lost 案例带中文 lost_reason。CSV 进 `data/seed/creators.csv, case_creators.csv, creator_products.csv`，load_seed 增对应 MERGE。

**达人 API**（新 `routes/creators.py`，全部过 PermissionPlan）：
- `GET /creators?q=&platform=&niche=&min_followers=&max_quote=&page=` → 列表（合作案例数聚合）
- `GET /creators/{id}` → 详情：属性 + promotes 商品 + collabs 案例列表（含 stage/lost_reason，按角色行列过滤）+ 汇总投放统计（复用 metrics.py 汇总比）

**模拟平台服务**（compose `mock-douyin`，端口 8100）：轻量静态站 + JSON API，页面三张——达人列表（搜索/筛选/分页）、达人详情（报价卡/历史合作/带货商品）、效果报表（日消耗/转化）；数据即种子达人（挂载 `data/seed/creators.csv`）。命名「星图·模拟」，与真实抖音无任何连接。

## 5. 各页面要点（M3–M5）

**客户页 `/brands`**：列表（健康度=近 30 天消耗/转化趋势 + case stage 分布）；详情 = Brand 子图：商品卡（spec/detail/price/target_age——本体现成）、案例列表（stage、**lost_reason「为什么没成」**、负责 Person）、汇总统计卡。`GET /brands`、`GET /brands/{id}`（新 `routes/brands.py`）。client 行过滤 external_for 锚点。

**财务/结算 `/settlements`**：Case 结算视图（bd_budget、gross_margin、settlement_status、合作达人报价合计），按状态/品牌筛选；角色门 `[management, finance]`（SETTLE_ROLES）。`GET /settlements`（新 `routes/settlements.py`）。

**数据看板 `/`**：echarts——大盘日消耗/转化趋势、平台分布、品牌 Top、达人 GMV Top、案例阶段漏斗；`GET /stats/overview`（新 `routes/stats.py`，unified_metrics 聚合全部走 metrics.py 的 `agg_expr` 汇总比，指标权限按 role 过滤；client 仅自己 brand_id）。

## 6. Agent SSE + 浏览工具（M6）

**SSE**：`POST /agent/chat/stream`（EventSource 不可 POST → 用 fetch ReadableStream 解析 SSE；旧 `/agent/chat` 保留供测试与兼容）。事件契约：
`{type: "thought", text}` / `{type: "tool_start", tool, args}` / `{type: "tool_step", step, desc, screenshot?}`（浏览工具子步，截图 base64 data URL）/ `{type: "tool_result", tool, result}` / `{type: "reply", text}` / `{type: "draft", case_draft?|creative_drafts?}` / `{type: "error"}`。
ReAct 循环重构为生成器逐事件产出（逻辑与现行 `_TOOLS` 注册表共用），每轮 LLM 输出的思考/动作解析为 thought+tool_start。

**浏览工具**：`_TOOLS` 注册 `fetch_creator_from_platform`（args: `{query?，creator_id?}`）——handler 用 Playwright（sync API 跑线程池）驱动 `ADKG_MOCK_DOUYIN_URL`：打开列表→搜索→点击详情→提取报价/粉丝/GMV，每步截图随 `tool_step` 事件流回；提取结果按 Q11A 直接入图（`GraphStore.upsert_entities` MERGE + provenance platform_api/80 + audit）。依赖：`uv add playwright` + `playwright install chromium`；部署镜像用 mcr.microsoft.com/playwright/python 基础镜像。

**前端时间线**：Agent 面板为**全局悬浮窗**（`AgentDock`，挂 AppLayout 常驻：关闭缩为悬浮球、`hidden` 切换保状态，所有角色可唤起）——宽度约束 ~420px，M6 的步骤组件须在此宽度可用。消息流内嵌：思考（可折叠灰底）、工具卡片（名+参数+结果摘要）、浏览步骤（动作描述+截图缩略图可点开）、最终回复 markdown、草稿卡（沿用现有 NodeCard/DraftCard）。
